Customer Support System

A complete guide to understanding how everything works

💡 What Is This System?

This is a Customer Support Question & Answer system. It works like a digital help desk where:

1

Anyone can ask questions

Customers type their question and submit it. The question is saved and ready to be answered.

2

Staff can answer questions

Support team sees unanswered questions and writes helpful answers.

3

Everyone can browse answers

All answered questions appear in a list. People can search and find answers to common questions.

Think of it like this...

Imagine a bulletin board in a store. People write questions on sticky notes, staff write answers on the same notes, and everyone can read the board to find answers without asking again.

⚙️ The Technology (Simplified)

You don't need to understand all this to use the system, but here's what powers it:

Next.js — The Brain

The main program that handles web pages and talks to the database. It decides what to show you based on what you click.

TypeScript — The Helper

A programming language that catches mistakes early. Like having a spell-checker for code — it prevents bugs before they happen.

Tailwind CSS — The Designer

Handles all the visual design — colors, buttons, spacing. It's why the app looks good without hiring a designer.

SQLite — The Filing Cabinet

Where all questions and answers are stored. It's a single file on your computer — simple and reliable.

Where Is the Data Stored?

All your questions and answers are saved in a file called customer_support.db in the project folder. It's like a tiny Excel file that lives on your computer.

🚀 How to Run the System

Follow these steps to start the system on your computer:

1

Open Terminal

Open the Terminal app (Mac) or Command Prompt (Windows). This is where you type commands.

2

Navigate to the Folder

Type: cd /path/to/customer_support — replace with the actual folder path.

3

Install Dependencies

Type: npm install — this downloads all the needed packages (first time only).

4

Start the System

Type: npm run dev — this starts the web server.

# Open Terminal and run these commands:
cd /path/to/customer_support
npm install
npm run dev

# Then open your browser and go to:
http://localhost:3000

That's it!

After running npm run dev, open your web browser and go to http://localhost:3000. You'll see the Q&A page and can start using the system!

🔮 What's Coming Next

The system is designed to grow. Here are the planned improvements:

Authentication (Login System)

People will need to log in to ask or answer questions. This keeps the system secure and tracks who said what.

Production Database

Right now, data lives on your computer. Later, we'll move it to a cloud database so it's accessible from anywhere and backed up automatically.

Deploy to Vercel

The system will be hosted on Vercel — a website hosting service. Anyone with the link will be able to use it.

Important Note About SQLite

The current database (SQLite) works perfectly on your computer, but it won't work on Vercel because Vercel's servers don't have a permanent file system. That's why we'll switch to a cloud database later.
