Database Schema

📋 questions

Column Type Description
id INTEGER Primary key, auto-increment
title TEXT Question title, not null
body TEXT Question body/description
created_at TEXT ISO timestamp, default now

💬 answers

Column Type Description
id INTEGER Primary key, auto-increment
question_id INTEGER Foreign key → questions.id
body TEXT Answer text, not null
created_at TEXT ISO timestamp, default now

Pages & Features

/qa

Q&A Page

Display all questions with their answers

  • Search bar to filter questions
  • Sort: Newest, Oldest, Most answers
  • Question cards with answer count
  • Expandable to show answers
/ask

Submit Question

Write and submit a new question

  • Title field (required)
  • Body textarea (optional)
  • Submit → POST to API
  • Redirect to /qa on success
/unanswered

Unanswered Questions

Questions waiting for answers

  • List questions with 0 answers
  • Inline answer form per question
  • Submit answer → POST to API
  • Auto-refresh after answering

API Routes

GET /api/questions

Fetch questions with optional filtering and sorting

  • search — Filter by title or body text
  • sort — newest | oldest | most_answers
  • unanswered — Return only questions with 0 answers
POST /api/questions

Create a new question

  • title — Question title (required)
  • body — Question body (optional)
POST /api/answers

Add an answer to a question

  • question_id — ID of the question to answer
  • body — Answer text (required)

Components

Navbar.tsx

Important Notes

⚠️ Deployment Considerations

  • SQLite works locally but not on Vercel (stateless serverless functions)
  • For production: swap to Vercel Postgres, Turso, or Supabase
  • Database abstraction layer will make the swap easy
  • No authentication for now — all operations are open
  • Future: Add Clerk authentication
  • SQLite file stored as customer_support.db in project root
  • Database auto-creates tables on first API call
